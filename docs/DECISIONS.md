# Architectural & Design Decisions (ADRs)

| ADR ID | Decision | Rationale | Alternatives Considered |
|---|---|---|---|
| **ADR-001** | **Fullstack Next.js App Router (TypeScript)** | Provides single-repository, unified type safety between backend API routes, deterministic calculation engine, and client-side design system. Fast compilation, standard Next.js routing, accessible SSR, and API endpoints. | Separate Express backend + Vite SPA (adds dual-process management overhead for local testing). |
| **ADR-002** | **Integer Minor Units (Paise) for Currency** | Prevents binary floating point rounding errors (`0.1 + 0.2 != 0.3`). All amounts stored in database as integers (paise, 100 paise = ₹1.00). Formatted strictly at presentation time with `Intl.NumberFormat('en-IN', { style: 'currency', currency: 'INR' })`. | Binary floating point `REAL/FLOAT` (causes penny rounding errors in revenue share). Decimal strings (slower arithmetic). |
| **ADR-003** | **Zero-Dependency SQLite / Embedded Storage with PostgreSQL-Ready Schema** | The spec suggests PostgreSQL; however, Windows development and hackathon evaluation environments frequently lack running Docker or PostgreSQL daemons. Using SQLite via Prisma/better-sqlite3 ensures immediate zero-friction evaluation, fast deterministic unit tests, and full relational integrity across all 22 required entities, while remaining 100% schema-compatible with PostgreSQL via Prisma schema provider. | Requiring external PostgreSQL server (blocks instant local setup). |
| **ADR-004** | **Adaptive Theme System via Local Clock** | Implements custom `ThemeProvider` with an inline `<head>` script to avoid FOUC. Computes milliseconds until next boundary (default 07:00 to 19:00) and schedules seamless transition with `setTimeout`, re-evaluating on `visibilitychange` and `focus` without page reload. Does not require location permission. | OS-only `prefers-color-scheme` (does not satisfy the required user-configurable time schedule). |
| **ADR-005** | **Provider-Agnostic AI Orchestrator with Sample Mode** | Central AI orchestrator queries deterministic analytics tools first, constructs structured context, and queries the LLM. If API keys (`GEMINI_API_KEY`, etc.) are absent, falls back transparently to schema-valid, evidence-grounded pre-computed responses with a visible "Sample AI response" badge. The LLM is never allowed to perform raw math or execute financial actions. | Hard requirement on external AI API key (causes test and offline demo failures). |
| **ADR-006** | **Deterministic Reconciliation and Funding Caps** | All matching rules (amount tolerances, date windows, reference hashing) and revenue-share cap repayments (daily percentage calculation up to the agreed cap) are deterministic code functions, covered by unit tests. | LLM-based calculations (forbidden by spec due to hallucination risks). |
| **ADR-007** | **Strict Tenant Isolation at API / Query Boundary** | Every business-scoped query requires `businessId` validation against the authenticated session / demo context. Cross-tenant access is tested and blocked at the data access layer, not just in UI menus. | Client-side filtering (vulnerable to IDOR attacks). |
| **ADR-008** | **Strict Compliance & Honest By Design** | Footfall in Location Explorer is explicitly labeled "Footfall: not measured". Review requests are non-gated and non-incentivized. Live funding switch is hard-locked as "BLOCKED" in the Admin Console. Simulated banners are persistent. | Fabricating footfall estimates or allowing sentiment-filtered review campaigns. |
